# mObywatel pod Twoją kontrolą

Koncepcja na mObywatel Challenge: asystent, który załatwia sprawy za Ciebie, ale nigdy bez Ciebie.

Każdą czynność podpisujesz na karcie z dokładną treścią. Granice asystenta są w kodzie, a nie w rozmowie. Każda sprawa zostawia ślad od prośby do decyzji urzędu. Widzisz, kto czytał Twoje dane, i cofasz zgody jednym ruchem. Zamiast listy usług są zdarzenia życiowe i sprawy bliskich.

Pełny opis: [KONCEPCJA.md](KONCEPCJA.md).

## Uruchomienie

To zwykła strona statyczna: `index.html`, `app.css`, `app.js`, `data.js`. Nie potrzebuje serwera, kont ani sieci. Otwórz `index.html` w przeglądarce albo wystaw folder dowolnym serwerem plików.

## Zastrzeżenie

Osoby i dane są fikcyjne. To nie jest aplikacja mObywatel ani usługa administracji publicznej. Prototyp nie używa godła ani oficjalnych oznaczeń mObywatela i nie łączy się z żadnym rejestrem.
